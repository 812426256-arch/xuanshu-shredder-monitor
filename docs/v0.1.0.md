# v0.1.0 · 安卓原型首版

- 中文监测主页显示设备上报的剩余时间、秸秆类型、档位、运行状态和连接状态。
- 内置 15 秒离线演示，覆盖待机、运行中、倒计时归零和已完成。演示页面持续显示「演示数据」。
- 实现 BLE v1 服务扫描、GATT 状态订阅和读取。状态缺失显示 `--:--`，有效状态过期或连接断开时清空旧数据。

## 安装包和验证

- 附件 `xuanshu-shredder-v0.1.0-debug.apk` 适用于 Android 6.0 及以上，使用调试签名。
- 蓝牙待实机联调。首版使用 [BLE v1 协议](BLE-v1.md)。
- APK 实测 **32,139 字节（31.39 KiB）**，可在 README 查看 SHA-256、安装方法和编译步骤。
- 在 Android 14 模拟器验证安装和演示流程，10 项单元测试通过。ESP32-S3 GATT 连接、通知、读取和断线仍待实机验证。
